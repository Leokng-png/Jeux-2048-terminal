# Fusion

Un jeu de réflexion qui se joue dans le navigateur : fais glisser les pierres,
fusionne celles de même niveau et atteins la pierre objectif.

## Jouer

Ouvre `index.html` dans un navigateur (double-clic sur le fichier). Rien à installer.

Pour y jouer en ligne (téléphone compris), active GitHub Pages sur le dépôt :
Settings → Pages → Source : la branche principale, dossier `/`.

## Règles

- Chaque coup fait glisser toutes les pierres dans une direction.
- Deux pierres de même niveau qui se touchent fusionnent en une pierre du
  niveau suivant et rapportent `niveau × 10` points.
- Après chaque coup, une nouvelle pierre (niveau 1, parfois 2) apparaît.
- 3 jokers par partie pour annuler ton dernier coup.
- La partie s'arrête quand plus aucun coup n'est possible.
- Grilles de 3×3 à 6×6, chacune avec son objectif et son record.

## Commandes

- Clavier : flèches ou `z` `q` `s` `d`, `u` pour le joker.
- Écran tactile : glisser le doigt sur le plateau.
